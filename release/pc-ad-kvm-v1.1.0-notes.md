## 独立 Wi-Fi 正式版

- 独立 Wi-Fi 模式中，ADB 只负责部署和启动；键鼠与可选剪贴板通过 Android 主动建立的局域网 TLS 连接传输。
- 支持 USB ADB 或无线 ADB 启动；就绪后可拔线、关闭无线调试，Android 的 USB 调试开关需保持开启。
- 增加固定证书校验、会话隔离、心跳、断线释放及有界自动重连；恢复连接后由用户重新接管。
- 保留 USB 传输、屏幕旋转、双次贴边、快捷键和共享剪贴板，修复遗漏松键事件造成的按键状态残留。

## 下载与安装

下载 `pc-ad-kvm-v1.1.0-windows-x64.zip`，完整解压后运行 `pc-kvm.exe`。先从托盘退出旧版，将 exe 与 jar 保持在同一目录。需要 Windows x64、.NET Framework 4.8 或更高版本及 Android platform-tools；Android 需支持 `/dev/uhid`。

PC 与 Android 必须能通过局域网 TCP 通信，PC 可使用有线网络。重启平板、同时关闭两种调试、设备进程退出、PC IP 改变或连续离线 30 分钟后，需重新通过 ADB 启动连接。
