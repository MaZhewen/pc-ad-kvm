# 设置窗口布局优化设计

## 背景

当前 `SettingsForm` 使用固定坐标摆放控件，窗口尺寸为 360 × 230。鼠标速度、手机相对位置和 adb 恢复选项都挤在同一平面上，速度值、单选项和风险说明之间缺少清楚的分组。用户在布局草图中选择了 A「分区单列」。

## 目标

让三个现有设置按操作顺序形成容易扫读的纵向区块，并让安全相关说明紧跟在对应选项下方。继续使用原生 WinForms 控件与当前对话框交互，不更改设置语义。

## 设计

设置窗体扩为宽松的单列布局，按从上到下的顺序展示：

1. **鼠标速度**：标题置左，当前倍率置右；滑块占满可用宽度，慢/快端点说明辅助理解。
2. **手机位置**：使用一个分组容器，明确标题“手机在显示器的哪一侧”，左侧和右侧单选项在同一行对齐。
3. **断联恢复**：强杀 adb 选项与现有影响说明放入同一区域，说明缩进并紧贴复选框，保持易读。
4. **操作按钮**：取消与确定靠右对齐并保持一致间距；确定仍为默认按钮，取消仍响应 Esc。

用 WinForms 布局容器组织这些区域，减少固定坐标导致的错位。表单继续为不可最大化、不可最小化的居中对话框；高度随内容增加，控件和间距留出清楚的视觉呼吸空间。

## 行为与兼容性

- 保留鼠标倍率范围 0.10–3.00、0.05 步进吸附与当前初始值裁剪逻辑。
- 保留左右位置、`AllowKillAdb` 读回及确定/取消行为。
- 不更改配置写盘、即时应用、托盘入口或 adb 恢复逻辑。
- 所有文案仍以中文呈现，并沿用 Windows 原生控件外观。

## 验收标准

- 三个设置区块和按钮顺序与上述设计一致，区块标题、当前倍率和辅助说明清晰可辨。
- 标签、滑块、单选项、复选框说明及按钮在正常窗口中无遮挡、不重叠。
- 改变设置并确定后，现有值仍按原逻辑写回；取消或按 Esc 不应用更改。
- 拖动速度滑块仍按 0.05 的增量吸附。

## 范围外

不增加新设置、图标、插图、侧边导航或主题切换；不重做托盘菜单；不调整鼠标或 adb 运行逻辑。
