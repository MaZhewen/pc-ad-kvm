# 设置窗口布局优化设计

## 背景

master 当前的 `SettingsForm` 包含鼠标速度、手机相对位置、断联时是否允许强杀 adb、是否启用双次贴边切换，以及可录制的全局切换快捷键。现有窗体仍使用固定坐标，尺寸为 360 × 382；设置项增加后，标签、帮助文字、快捷键错误提示和按钮沿同一列排布，区块关系不够清楚。

用户已选择 A「分区单列」布局。本次调整将设置按用途分组，并纳入 master 已有的双次贴边开关和快捷键设置。

## 目标

- 让当前所有设置在单列窗口内形成清楚、可扫读的分区。
- 让设置说明和校验错误紧邻相应控件。
- 为以后新增设置提供稳定的分组、排版、校验与保存规则。
- 保留各设置已有的配置语义和运行行为。

## 布局

从上到下安排以下区块：

1. **鼠标速度**：标题置左，当前倍率置右；滑块占满可用宽度，慢/快端点说明辅助理解。
2. **手机位置**：标题明确说明手机相对显示器的位置；左侧和右侧单选项在同一行对齐。
3. **切换方式**：包含“启用双次贴边切换”复选框和全局切换快捷键录制框。快捷键说明与校验错误放在录制框下方；关闭贴边开关时的提示说明快捷键仍可用于切换。
4. **断联恢复**：强杀 adb 选项与现有影响说明放在同一区域，说明缩进并紧邻复选框。
5. **操作按钮**：取消与确定靠右对齐并保持一致间距；确定为默认按钮，取消响应 Esc。

使用 WinForms 布局容器组织区块和行内对齐，避免新增项目依赖手工固定坐标。对话框继续居中、不可最大化或最小化；尺寸应一次容纳完整内容。增加设置时扩展对应区块和窗体尺寸，避免压缩间距、裁切文字或重叠控件。确认和取消按钮固定在可见底栏，区块空间不足时由内容区滚动，不能把操作按钮挤出屏幕。

## 视觉风格

- 保持浅色方案：窗口底色为 `#F4F7FB`，内容区使用白色卡片和 `#DFE5ED` 细边线；区块标题、主要文字使用 `#233044`，帮助文字使用 `#68778B`，并保持清楚的字体层级和稳定间距。
- 用卡片标题替代 WinForms 凹槽式 GroupBox 标题；区块边缘轻、标题清晰，不添加装饰性图标或大面积色块。
- 使用无衬线的 Microsoft YaHei UI 9 pt，避免中文字符回退到衬线字体；区块标题加粗，鼠标倍率用蓝色突出。确定按钮使用 `#2563EB` 蓝色强调样式及白字，取消按钮使用白底和浅灰边线；按钮保留清晰焦点态，键盘确认和 Esc 取消仍有效。
- 保留 WinForms 原生交互控件。鼠标速度滑块隐藏非必要刻度，显示当前倍率和慢/快端点；位置单选、开关、快捷键输入框沿用原行为。
- 对话框基准客户区为 460 × 720，并根据当前屏幕工作区限高；仅内容区滚动，底部按钮栏固定可见。仅有一种浅色外观，不增加主题切换。
- 样式必须适配系统 DPI，卡片宽度跟随单列内容区，错误提示换行后内容区能正常扩展。

## 启动与设置窗口入口

- 首次启动在后台初始化和托盘安装完成后自动打开现有设置窗口，让双击 pc-kvm.exe 有可见反馈。
- 程序已运行时再次启动 pc-kvm.exe，第二个进程不重复初始化输入、网络或设备资源；它通过进程间信号请求现有实例打开设置，然后退出。
- 系统托盘图标双击与托盘菜单“设置…”共用同一个设置窗口入口。设置窗口已打开时，新的请求激活现有窗口，不再创建重复对话框。
- 第二个进程无法联系现有实例时，显示可见错误提示，不能静默退出。
- 单实例协调使用当前用户会话范围内的命名实例互斥体、请求互斥体、自动重置请求事件和自动重置逐请求应答事件；回调须切回 WinForms UI 线程后才能打开窗口。第二次启动须等主实例在 UI 线程实际接收本次请求后再退出；若启动失败、关闭竞态或等待超时，第二个进程显示可见提示。

## 现有行为

- 双次贴边切换默认开启；关闭后双向贴边切换停用并清除待完成的第一次触边，快捷键切换仍然可用。重新开启后，鼠标需要先离开 PC 边缘，新的触边序列才可开始。
- 全局快捷键默认是 `Ctrl+Alt+Space`。用户可在只读输入框中按组合键录制；组合键需包含 Ctrl 或 Alt 以及一个非修饰键。`Ctrl+Alt+Esc` 保留为紧急退出，不能分配给切换。
- 快捷键注册失败时，窗体保持打开，在快捷键区域显示冲突提示；旧快捷键及已保存配置继续有效。
- adb 强杀选项沿用当前默认值和风险说明；其他速度、设备位置和快捷键设置沿用 master 当前配置实现。

布局任务只整理控件位置与层级，不改写上述行为。双次触边与快捷键的完整状态机规则以 [`2026-09-29-double-edge-and-hotkey-design.md`](2026-09-29-double-edge-and-hotkey-design.md) 为准。

## 新增设置的统一规范

以后新增设置选项时，必须遵循以下约定：

- **先归入语义分组**：放入最相关的现有区块；只有独立概念才新建区块，并按用户操作顺序排列。不得把新控件无分组地追加在窗体底部。
- **沿用单列排版**：标题、当前值、输入控件和按钮按既有对齐规则排列；说明与控件相邻，长文字可换行；错误信息预留空间并显示在出错控件附近。
- **沿用视觉与布局容器**：交互沿用 WinForms 原生控件，区块使用统一的浅色卡片、细边线、字体层级和间距。新增项目时扩充对应卡片；超出可见高度时扩展滚动内容区，不以缩小字号、挤压既有区域或遮挡信息换取空间。
- **完整定义配置行为**：在设计中记录默认值、有效范围或格式、无效输入反馈、保存时机和运行时效果；UI 只有在校验通过并确认后才提交值，取消或按 Esc 不应用暂存改动。遇到冲突时须保留此前有效配置。
- **同步验收内容**：每个新增设置都要补充相应验收项，覆盖显示与校验，并验证配置往返及确认/取消语义；涉及输入切换行为时，也要验证对应运行时效果。

## 行为与兼容性

- 保留鼠标倍率范围 0.10–3.00、0.05 步进吸附与当前初始值裁剪逻辑。
- 保留左右位置、`AllowKillAdb`、`EnableEdgeSwitch`、`SwitchHotkey` 的读回与配置保存逻辑。
- 保留快捷键捕获、冲突注册失败提示和之前有效快捷键回退行为。
- 不更改配置格式、即时应用、托盘入口、触边状态机或 adb 恢复逻辑。
- 所有界面文案使用中文；交互保持 Windows 原生键盘和焦点行为，视觉使用本设计定义的浅色卡片样式。

## 验收标准

- 鼠标速度、手机位置、切换方式、断联恢复和按钮按上述顺序分区，标题、值、帮助文字和错误提示可辨认。
- 所有当前控件和文案在正常窗口中无遮挡、不重叠；扩展区块时布局容器和窗体尺寸可同步增长。
- 双次贴边复选框反映当前配置；快捷键框展示当前组合键，帮助和注册冲突提示出现在该区块内。
- 现有设置在确认后仍按原逻辑写回；快捷键校验失败不会保存新值；取消或按 Esc 不应用暂存更改。
- 速度滑块仍按 0.05 的增量吸附。
- 新增设置符合“新增设置的统一规范”，并有覆盖显示、校验、保存及适用运行行为的验收项。

## 范围外

不增加新的运行时功能或配置项；不重做托盘菜单；不添加装饰性图标、插图、侧边导航或主题切换；不调整鼠标、触边、全局快捷键注册或 adb 恢复逻辑。
