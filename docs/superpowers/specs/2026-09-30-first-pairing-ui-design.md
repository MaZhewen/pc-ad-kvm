# 首次无线配对与连接方式切换设计

状态：用户已确认。

## 目标

首次使用时可在连接窗口切换 USB / 无线调试，手动输入设备 IPv4 和六位配对码完成 Android 11+ 无线调试配对。Android 配对服务使用独立的随机端口；若 mDNS 能发现同一 IP 的 `_adb-tls-pairing._tcp`，界面自动填入配对端口；否则用户输入手机「使用配对码配对设备」弹窗显示的端口。连接服务端口仍需另外发现或在主页面手填，配对成功本身不代表 KVM 已连接。

## 界面与数据流

- 顶部现有「连接方式」明确保留 USB / 无线两个选项。切到 USB 时禁用无线地址、扫描和配对控件；切到无线时启用。
- 「首次配对」区域提供独立的 IP、配对端口和六位码字段，以及「查找端口」「配对」「取消配对」。IP 只接受规范 IPv4；端口只接受 1–65535。配对码仅在点击配对时取出并清空，不写入配置或日志。
- 「查找端口」异步查询 ADB mDNS，筛选同一 IP 的 pairing 服务。恰好一个候选时填入端口；多个候选时列出供选择；没有候选时保留手填入口并提示查看手机弹窗。
- 点击「配对」时若端口已填，直接调用现有 `ConnectionCoordinator.Pair(IP:port, code)`；若端口空白，先查找候选，只有唯一候选才继续配对。无候选或多候选时不尝试猜测端口，提示用户手填/选择。
- 配对成功后在连接地址栏预填 IP，再刷新设备和连接服务。用户继续点击「扫描端口」或手填手机无线调试主页面的连接端口，最后点击「连接」。关闭窗口或切换模式不会意外提交旧的查找结果。

## 代码边界

- `WirelessDiscovery.cs` 新增 pairing 服务解析，保留现有 connect 服务解析语义。
- `ConnectionCoordinator.cs` 提供可取消的 pairing 服务列表；现有六位码校验与 stdin 传递不变。
- `ConnectionForm.cs` 负责三字段、异步端口查找、模式开关和配对成功后的下一步提示。
- README 说明配对端口与连接端口分别来自手机的不同页面，IP 单独输入，但若 mDNS 不通仍必须填手机显示的配对端口。

## 验收

- pairing 服务不进入连接服务列表；只选择输入 IP 的 pairing 服务。
- 无 mDNS 时，手动 IP + 配对端口 + 六位码可发起配对；缺端口不调用 `adb pair`。
- 自动发现唯一端口可填入并配对；多个候选不盲选。
- USB / 无线切换正确启停控件；旧异步结果不覆盖新输入。
- 配对码前导零保留且不进入配置/日志；配对成功后连接地址预填 IP。
- 全部离线测试和 Windows 构建通过；实际配对需要手机弹窗里的临时代码。
