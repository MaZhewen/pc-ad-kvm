# 手动连接与设置界面修复设计

用户反馈确认的目标：连接端口和配对端口都由用户手动输入；首次启动和托盘双击显示原设置窗口；连接窗口沿用设置窗口的配色、字体、白色卡片与按钮样式。

## 交互

- 连接窗口保留 USB／无线切换、在线设备选择、ADB 路径、配对和连接管理。无线连接地址输入手机无线调试主页面的 `IPv4:连接端口`；首次配对分别输入手机配对弹窗的 IP、配对端口、六位码。无扫描、查找或自动补全端口入口。配对成功只预填 IP 并提示补齐连接端口。
- 首次启动与托盘双击显示原 `SettingsForm`，保留鼠标速度、手机位置、切换方式、断联恢复及保存行为。托盘菜单继续提供「连接设备…」；设置窗口增加同名入口。
- `ConnectionForm` 使用与 `SettingsForm` 相同的浅蓝灰背景、深色文字、白色带细边框卡片、蓝色主按钮与浅色次按钮。表单内容可滚动，底部操作区固定，缩放时不遮挡控件。

## 边界与验收

- 删除 UI 中的 TCP 端口扫描和配对端口查找流程，手动输入无需等待网络搜索。
- 保留 ADB 设备枚举及已有已连接设备选择；连接地址只在手动输入完整端口后提交。保留配对码的六位数字校验、输入后清空与 stdin 传递。
- 设置项和运行时应用逻辑沿用现有实现；首次启动、托盘双击及菜单入口行为可验证。
