# 连接主界面实施计划

用户已选择「连接主界面 + 次级设置」。在当前工作区实施，保留已有未跟踪文件。

目标：启动和托盘统一打开设备连接页，持续反馈设备是否就绪及控制对象；设置保持次级入口。

1. 扩展 connection-form 行为测试：USB 隐藏无线区域、首次配对折叠、手动断开后操作恢复、局部校验保留配对码、状态卡与控制状态。先运行确认新断言失败。
2. ConnectionCoordinator 提供线程安全状态快照（就绪、恢复意图、配对、设备、错误）；状态不由 UI 解析中文推断。失败原因独立保留，显式重试和成功后清除。
3. ConnectionForm 顶部固定状态卡；连接成功收起配置，展示切换说明。USB 隐藏无线卡，首次配对按需展开。按钮按快照更新。刷新及输入错误使用独立反馈区。设备列表保留未授权与离线提示。
4. Program、TrayUi 统一入口，托盘文字反映连接/接管状态，图标保持原版；设置保存返回主界面，明确设置期间切换快捷键暂停。保持非模态窗口以免破坏接管焦点。
5. 更新 README。运行 connection-form、coordinator、single-instance、message-host 回归和 Windows 构建；查看表单渲染检查短屏布局。真实无线链路和实际接管留作真机验收，不能用离线测试代替。

## 实施与验证结果

- 上述五项已完成；未更改原有手动端口输入方式及非模态设置窗口。
- 独立审查发现并修复：配置错误未暴露、部分无线失败缺少重试提示、主动取消被误报为超时。三个回归分别观察到失败后修复通过。
- 最终 connection-form、coordinator、single-instance、message-host、connection 五组测试命令均成功退出。message-host 的真实前台接管检查因环境无交互前台窗口跳过；其余执行的断言通过。
- 已查看未连接及正在控制两种表单渲染；小屏固定操作区由布局回归验证。
- Windows x64 编译成功，最终含原图标的程序输出到 `dist/connection-home-original-icon/pc-kvm.exe`，配套当前新鲜的 pckvm.jar，并复制现有 ini。运行中的旧程序未被强制终止。
- 未做真机连接验收；无关的未跟踪文件保持原样。
