## 关口与记录要求

1. D02–D04 是可行性关口：工具存在和本机测试不足以放行；若零 APK 进程无法存活，先报告技术事实，不继续扩大改动。
2. D05–D09 是协议与安全关口：input sessionId、clipboard sessionId、PC generation、几何 epoch 和 READY 各自有独立含义，不能互相代替。
3. D10–D12 是产品集成关口：运行期不依赖 ADB；USB 模式、旧配置及已绑定设备身份必须保留。
4. D13–D15 是交付关口：真实漫游无法复现时标记未验收，不用断 socket 结果代填；企业网络阻断记录为适用环境限制。

每项完成时追加执行日期、实际命令或操作、结果、证据路径及剩余限制。当前没有需要用户先裁决才能写完文档的问题；30 分钟离线期限、固定 PC 地址和 .NET 4.8 是明确的本版默认及适用边界，可在审阅时调整。
