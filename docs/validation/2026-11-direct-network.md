# 独立 Wi-Fi 验证状态

适用环境为 Windows x64、.NET Framework 4.8 以上，以及已实测的 Android 16 小米平板。Android 的 USB 调试开关保持开启。可通过无线 ADB 启动，运行期间可关闭无线调试并拔掉 USB 线。

- USB 和无线 ADB 分别启动的探针通过五分钟存活验证。无线引导后关闭无线调试，再切换 WLAN，同一进程在 9.8 秒内恢复 TLS 数据往返。
- 正式程序日志已达到就绪。发版前的 11 组自动化回归通过，覆盖协议、部署、重连、键鼠会话和剪贴板接线。
- 真实 BSSID 漫游、60 分钟亮屏长测和完整键鼠与剪贴板真机矩阵仍待验收。本次以预发布版本提供。
